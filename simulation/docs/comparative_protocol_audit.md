## 2. 现有初始无穷界与共同有限物理边界

`jas/reference.py:envelope`在t=0给`mu_a=mu_b=ell`。因此原物理界为

```text
U_J = atanh(mu_a/ell)/chi,
L_J = atanh(mu_b/ell)/chi,
```

其中实际误差域是`-L_J<e<U_J`，L表示正的下界幅值。t=0时两者无穷；原变换本身对任意有限e仍有定义。不能把无穷U/L输入传统logBF，不能把logBF的零斜率/NaN当方法失败。也不能偷偷将Full内部`mu(0)`改成小于ell后继续引用原“任意有限初值”初始化条件。

建议保留Full及原BF各消融内部原始mu，另外预先固定所有方法共同使用的有限物理评价边界`U_c,L_c`，同时供conventional_BF内部使用。前1 s共同有限界是Full理论BF界之外的额外数值任务要求，必须直接检查实际轨迹是否满足；这不是原定理已经保证的更强结论。1 s后它与原物理界完全相同。

可用运行前固定的轴向向量（单位分别为m和rad）：

```text
U0 = [.08,.07,.07,.22,.20,.22],
L0 = [.09,.07,.08,.25,.20,.23],
tau = 1 s.
```

所有比较初值都须严格满足`-L0<e0<U0`并保留明确正裕量。现有large偏移为`[-.045,.030,-.035,-.07,.05,-.06]`：乘2使x恰等于`-L0_x`，反号乘2还超过`U0_x`，因此scale2不属于这个共同logBF合法域。不能将其送入传统BF再记为控制失败。

对上/下各自定义

```text
kappa0_a = tanh(chi*U0),
kappa0_b = tanh(chi*L0),
Q(s) = 10*s^3 - 15*s^4 + 6*s^5,
kappa(t) = kappa0 + (1-kappa0)*Q(t/tau),  0 <= t <= tau,
kappa(t) = 1,                            t >= tau.
```

Q在两端的一阶、二阶导数为零。0<t<tau时

```text
kappa_dot = (1-kappa0)*(30*s^2-60*s^3+30*s^4)/tau,
kappa_ddot = (1-kappa0)*(60*s-180*s^2+120*s^3)/tau^2.
```

t>=tau时两者取零。对任一原mu及其相应kappa，令

```text
z = kappa*mu/ell,
z_dot = (kappa_dot*mu + kappa*mu_dot)/ell,
z_ddot = (kappa_ddot*mu + 2*kappa_dot*mu_dot + kappa*mu_ddot)/ell,
B = atanh(z)/chi,
B_dot = z_dot/(chi*(1-z^2)),
B_ddot = z_ddot/(chi*(1-z^2))
         + 2*z*z_dot^2/(chi*(1-z^2)^2).
```

用mu_a/kappa_a得到`U_c`，用mu_b/kappa_b得到正幅值`L_c`。在t=0有`B=U0/L0`，所有量有限；t=tau时函数及前两阶导数与原物理界相接。实现不得只改值却沿用原mu的导数。还须确认`0<z<1`及数值裕量，不靠裁剪z去隐藏非法包络。

该构造的单调性并非仅凭Q单调就自动成立；过渡段要检查`kappa_dot*mu+kappa*mu_dot`的符号。若采用具有单调边界假设的文献基准，只有满足其假设的场景才属于其正式理论比较。非单调放宽可以作为明示的扩展试验，但不能泛称所有传统BF都不能处理正的边界导数。

若希望各方法内部都严格施加同一有限界，可另定义mu_c=tanh(chi*U_c/L_c)*ell供JAS-BF使用，但mu_c(0)<ell，此时是共同有限合法域初始化的变体；不能同时冒充保留原任意初值初始化的Full。当前推荐前述“原内部BF+共同外部评价界”方案，避免混淆。

## 3. 有限域logBF及全部导数

以下每个轴独立计算。令`U(t)>0,L(t)>0`为第2节共同边界；L是正幅值，域为`-L<e<U`。固定常数`c>0`，定义

```text
p = e + L,
q = U - e,
xi = c*[log(p)-log(q)-log(L)+log(U)].
```

这样`xi(e=0,t)=0`，且两侧靠近边界时发散。由`xidot=a*edot+b`，有

```text
a = c*(1/p + 1/q),
b = c*(Ldot/p - Udot/q - Ldot/L + Udot/U).
```

总时间导数只使用e、edot与已知包络导数：

```text
adot = c*[-(edot+Ldot)/p^2 - (Udot-edot)/q^2],

bdot = c*[Lddot/p - Ldot*(edot+Ldot)/p^2
          - Uddot/q + Udot*(Udot-edot)/q^2
          - Lddot/L + Ldot^2/L^2
          + Uddot/U - Udot^2/U^2].
```

不得把`adot`当固定e的偏导。`bdot`包含edot，但不需要e的加速度。若接口中的lower存的是负边界值`ell_bound=-L`，须先取`L=-ell_bound`，其一二阶导数也同时取负；上述公式不能直接将负lower当L代入。

建议在唯一、预先指定的设计点`e=0,t=0`匹配原JAS斜率：

```text
a_JAS(0,0) = chi/ell,
c = (chi/ell)/(1/L0+1/U0).
```

c按轴固定，不在线随包络改变。匹配只发生在指定点，不能声称两种非线性坐标全域相同；不同BF的xi/S数值及原始Gram最小特征值不可直接作为横向性能排名。

域外`p<=0`或`q<=0`必须记录并停止该方法的合法BF积分，保存失败前数据与原因；不夹e、不取绝对值、不添加epsilon继续伪造定义域内轨迹。域内宜用上述log差式避免先计算很大/很小的比值。

## 4. 其他四个消融的精确定义

### 4.1 no_BF（可选定义，本轮不运行）

可采用预先固定`c_e=chi/ell`的线性坐标：

```text
xi = c_e*e,
xidot = c_e*edot,
a = c_e, b = 0, adot = 0, bdot = 0.
```

它匹配Full在初始零误差点的局部坐标斜率，且定义于所有有限误差，但没有BF强制约束机制。仍按相同`U_c/L_c`评价实际轨迹。某一条轨迹未越界不意味着该消融也有约束保证；不能人为制造边界违规后才作选择。若选`xi=e`也合法，但须披露单位/尺度改变，不能简单以相同数字增益宣称公平。

### 4.2 linear_surface

固定正对角L_s，定义

```text
g(xi) = L_s*xi,
xidot_r = -L_s*xi,
xiddot_r = -L_s*xidot,
S = xidot + L_s*xi.
```

随后正常重算关节参考与Y。理想S=0时`xi_i(t)=xi_i(t_r)*exp[-L_s_i*(t-t_r)]`；从r0>delta进入delta的时间是`log(r0/delta)/L_s_i`，对无界r0不存在统一上界。这是线性滑动机制的严格数学结论，不能仅凭有限机器人扫初值作全局证明。

可在运行前以`L_s=Lambda1*h'(0)`匹配Full局部斜率，其中`h'(0)=(3-alpha)*delta^(alpha-1)/2`。也可明确选一个独立设计尺度匹配函数幅值，并按共同力矩预算一次性整定；两种策略须先选一种冻结。不能逐初值降低对照增益以制造较慢对照。局部匹配的线性面可能在有限范围更快，这是应保留的真实结果。

### 4.3 linear_reaching

Full中的

```text
-K2*Sig^upsilon1(S) - K3*Sig^upsilon2(S)
```

本轮整体删除，使用原本已存在的`-(Ka+rho)*S`作为线性耗散。没有暗中再加入一个K_L。前馈、先验投影和`-Y^T*R*sign(Y*S)`均保持原式，因此对应OriginalController仅令K2=K3=0的精确力矩差分。

若未来另作“等幅匹配线性替代”试验，可在一个固定非零设计S尺度s_star按轴选附加K_L：

```text
K_L = K2*s_star^(upsilon1-1) + K3*s_star^(upsilon2-1).
```

这不是本轮实现；不能把该建议参数当作已经施加的力矩。由于次线性项在零点的斜率无穷，不能声称在S=0进行了有限斜率匹配。

该消融只检验去掉所提双幂次到达项的效果。保留的鲁棒sign仍可能产生额外有限时间作用，因此不得命名为“已证明非固定时间的原系统”。只把K2置零或只把Lambda2置零，也不构成一般完整闭环非固定时间的证明。

### 4.4 no_history

令实际学习方向为

```text
mu = -Y*S,
theta_dot = Upsilon*Pr_box(mu).
```

Upsilon、初估、先验、逐分量投影与离散步不变。仍可独立计算过滤/Gram/IE供事后诊断，但不得把历史预测误差送进更新。需要保存实际分项学习方向，防止仅将曲线标签改为no_history。该方法是学习消融，不满足原正gamma完整CL的所有结论；它在某些持续激励轨迹仍可能收敛，不能因为没有原IE定理就断言它不可能指数收敛。

## 5. 最精简的机器人运行矩阵

主对比使用3个既有工况乘6种方法，每组24 s。各方法共享物理plant、抓持、初始物理状态、期望运动、左右`Fy=-5/+5 N`及其它零分量、控制/物理周期、积分器和硬件限制；五个JAS内部方法还共享物理先验和初估。三工况都显示误差/界、力与广义力矩、力矩峰值；具有参数学习器的方法再显示参数/预测误差、IE与实际投影活动。外部完整方法若没有该估计器，应明确标注不适用，不能造零误差或假IE。无需把6条曲线都塞进每张图。公共物理误差指标用于跨BF/滑动面比较，xi/S仅用于相同坐标或清楚标注的阶段诊断。

独立初值扫描已固定只用Full、linear_surface、linear_reaching三组，每组8 s恒定目标，而非再扩展一个不隔离阶段的外部方法。8个物理初值为

```text
e0 = sign*scale*large_offset,
sign in {-1,+1},
scale in {.25,.5,1,1.5}.
```

每个初值先完成共同严格域、IK、关节/Jacobian/Euler图及零初速一致性检查，再对所有方法使用相同初态。不能为某个方法单独剔除不利但合法的初值。若有预先规定的物理不可行状态，应在所有方法运行前一并排除并记录。8 s恒定目标/保持任务可作为初态机理扫描；若8 s没有进入，记录右删失，不作“理论失效”判断，除非已验证其应满足的全部假设及合法时间上界小于观察时长。

上述扫同时改变xi0与S0，所以它是整个闭环的初值敏感性检验，不能独自隔离两个阶段。若需额外隔离到达阶段，可固定同一合法e0并扫初速：`edot0=a^-1[S0-g(xi0)-b]`，再经同一刚性抓持运动学构造关节速度；这会增加运行量且仍须检查速度限制。滑动阶段最清楚的机制对比采用第6节同xi0的精确标量方程；不要求机器人以不同速度初始化却误称同一物理初态。

建议一次固定各替代块的整定点及资源预算，再冻结全部方法和全部初值的参数。不能逐工况重调，也不能用未知真值或实际反力给某一方法额外初始化/反馈。完整外部基准若需要额外传感或集中通信，应在信息条件表明确，不可被包装成同样的无测力分布式方法。

## 6. 两阶段固定时间的独立标量机理检验

这些方程是机制/比较系统检验，不是新的机器人控制器，不取代完整MuJoCo结果。

### 6.1 双幂次到达比较系统

对`r>=0`，取

```text
rdot = -a*r^(1+nu) - b*r^(1-nu),
a,b>0, 0<nu<1.
```

精确到零时间为

```text
T(r0) = atan[sqrt(a/b)*r0^nu]/(nu*sqrt(a*b))
      < pi/(2*nu*sqrt(a*b)).
```

对照线性方程`rdot=-k*r`从r0进入epsilon的时间是`log(r0/epsilon)/k`，精确到零非有限；单一亚线性幂次方程`rdot=-b*r^(1-nu)`的精确时间为`r0^nu/(b*nu)`；即使再加线性耗散`-k*r`，时间也为`log[1+(k/b)*r0^nu]/(k*nu)`，对r0仍无统一上界。用对数均匀r0可直接核对解析式与数值求解，展示双幂次项的作用。

若使用论文能量比较系统，应取`r=Vhat`、指数`(1+upsilon1)/2`与`(1+upsilon2)/2`及对应a/b，不能将表面变量S的指数与能量指数混用。原`Tr=pi*psi/(2*sqrt(hat_lambda1*lambda2))`对应能量系统的`nu=1/psi`。

这个标量线性/单幂对照没有保留机器人中的状态相关鲁棒sign，因此不能据它证明linear_reaching完整机器人闭环必定非固定时间。

### 6.2 滑动阶段及C1层

在理想S=0且r=|xi|>=delta时，

```text
rdot = -Lambda1*r^alpha - Lambda2*r^beta,
alpha=1-nu, beta=1+nu.
```

令`K=sqrt(Lambda2/Lambda1)`，从r0>=delta进入delta的精确时间是

```text
T_delta(r0) = [atan(K*r0^nu)-atan(K*delta^nu)]
              /(nu*sqrt(Lambda1*Lambda2))
           < pi/(2*nu*sqrt(Lambda1*Lambda2)).
```

可与linear_surface的`log(r0/delta)/L_s`在相同r0和同一delta对比。若继续积分进入层内，必须保留原C1多项式h；不能在层内偷偷换成非Lipschitz幂次后声称原法精确固定时间到零。原文主张的是层进入的固定时间以及层内后续渐近收敛。

## 7. 容差、保持与理论界的合法使用

采样进入时间统一定义为：在不晚于`H-hold_min`的保存时刻中，取最早的t，使从t至终点全部保存时刻都满足指定容差；`hold_min`至少1–2 s，运行前固定。否则记未证实进入/右删失。不能仅取第一次穿越，不能为某个方法单独放宽容差。

分别报告：

1. 达到面邻域的`T_S(epsilon_S)`及是否保持；
2. Full坐标进入`max|xi|<=delta`的时间，和全部方法共同物理误差容差的时间；
3. 第二项时间减`T_S`的实际延迟，但只作采样实践指标；
4. 容差一半/两倍的敏感性，以及实际输入/关节/域限制。

`|S|<=epsilon_S`不是理论的`S=0`，因此采样延迟不能直接当严格Ts验证。不同滑动面定义S不同，不能仅比S数值大小排名。跨结构主要比较相同物理误差容差，可用Full的理论半径`asinh(2*ell*delta)/(2*chi)`作为共同、运行前固定的一种物理容差，同时给更严格的工程容差，避免只报一个宽松阈值。

`Tr`必须使用运行前指定的统一合法配置域上的`z_u,Jdag`等界，不能将各条已完成轨迹的采样最大惯量称为全域上界。若无法给出可信全域界，应只给条件性公式/标量机制结果及机器人观测时间，不能画一个采样拟合界宣称证明原定理。有限8点或10点扫描不证明任意有限初值；任意有限误差也不代表机械臂任意关节配置、不可达姿态或电机饱和后仍在理论适用域。

## 8. CL残差相关最终界的比较边界

历史通道比较应主要在Full和no_history之间进行，因为BF/滑动面/回归相同。改变变换后Y的尺度与原始Gram特征值都改变，不能将不同方法较大的原始lambda_min当作更强物理激励。每个方法的原始IE仍可按其自身实际回归记录。

有限激励后保持任务应同时检查后续实际`Yf`的滚动Gram，不得仅凭参考速度归零就声称没有PE；原sign可能维持细微运动。窗口、滤波率、omega均在运行前固定；不得看真值误差后在线挑窗，也不得加正则假IE。

Theorem 1的共同IE时间是`Te=max_i Te_i`，不是强制各臂同步触发。其结论为

```text
V(t) <= exp[-varpi*(t-Te)]*V(Te)
        + (C_zeta/varpi)*(1-exp[-varpi*(t-Te)]),
C_zeta = sum_i gamma_i*norm(zeta_i)^2/(2*omega).
```

非零冻结残差允许非零最终误差；真值误差曲线不要求逐时单调。投影盒保证的有界性与该结论相容，却不单独验证这个指数包络。当前参数可能使理论残差半径被先验盒帽主导，这种保守或无信息的界应照实保留，不能用轨迹拟合率替换理论varpi。无历史通道也不应被预先判为发散或无法学习。

## 9. 独立实现核对建议

## 10. 外部完整 PPC 的独立核对
